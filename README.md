# পরিবারের আয়-ব্যয় ট্র্যাকার (Family Expense Tracker Bangla — Redesign Edition)

একটি আধুনিক, প্রিমিয়াম এবং সম্পূর্ণ বাংলা ভাষার পারিবারিক আয় ও ব্যয় ব্যবস্থাপনা ওয়েব অ্যাপ্লিকেশন। আধুনিক SaaS ড্যাশবোর্ড, নরম থ্রি-ডি (Soft 3D) কার্ড, রঙিন গ্রেডিয়েন্ট, গ্লাস মরফিজম এবং দৃষ্টিনন্দন বাংলা টাইপোগ্রাফির সমন্বয়ে এটি তৈরি করা হয়েছে।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. ৮টি রঙিন ৩ডি (3D) ইন্টারেক্টিভ ড্যাশবোর্ড কার্ড
ডেস্কটপে ৪টি কলাম × ২টি রো এবং মোবাইল/ট্যাবলেটে ২টি কলামের রেসপনসিভ গ্রিড:
1. **মোট আয় (Card 1):** নির্বাচিত সময়ের মোট আয়ের হিসাব (সবুজ/টিয়াল গ্রেডিয়েন্ট)। ক্লিক করলে সরাসরি আয়ের তালিকায় নিয়ে যায়।
2. **মোট খরচ (Card 2):** নির্বাচিত সময়ের পারিবারিক খরচের যোগফল (কমলা/কোরাল গ্রেডিয়েন্ট)। ক্লিক করলে ব্যয়ের তালিকায় নিয়ে যায়।
3. **বর্তমান ব্যালেন্স (Card 3):** আয় থেকে খরচ বাদে অবশিষ্ট সঞ্চিত টাকা (নীল গ্রেডিয়েন্ট)।
4. **মোট লেনদেন (Card 4):** সংরক্ষিত হিসাবের মোট সংখ্যা (পার্পল গ্রেডিয়েন্ট)।
5. **আয় যোগ করুন (Card 5):** আয়ের এন্ট্রি ফরম খোলার অ্যাকশন কার্ড (＋ সবুজ গ্রেডিয়েন্ট)।
6. **খরচ যোগ করুন (Card 6):** খরচের এন্ট্রি ফরম খোলার অ্যাকশন কার্ড (− গোলাপি/কমলা গ্রেডিয়েন্ট)।
7. **রিপোর্ট ও হিসাব (Card 7):** মাসিক ও বার্ষিক বিশ্লেষণ ও চার্ট (সায়ান/ইন্ডিগো গ্রেডিয়েন্ট)।
8. **ব্যাকআপ ও ডেটা (Card 8):** ডেটা সুরক্ষা ও গুগল ড্রাইভ ব্যাকআপ (রয়্যাল নেভি গ্রেডিয়েন্ট)।

### ২. কমপ্যাক্ট বাংলা নেভিগেশন ও হেডার
* **ড্যাশবোর্ড:** ৮টি কার্ড, চলতি মাস/বছরের ফিল্টার, মাসভিত্তিক বার চার্ট ও খরচের খাতের পাই/বার রেশিও।
* **আয়-খরচ:** সম্পূর্ণ লেনদেন তালিকা, তাৎক্ষণিক সার্চ, ধরন (আয়/ব্যয়), খাত, বছর ও মাস অনুযায়ী ফিল্টারিং, এডিট ও ডিলিট কনফার্মেশন।
* **নতুন লেনদেন:** এক ক্লিকে পপআপ ফরম খোলার সরাসরি মেনু বাটন।
* **রিপোর্ট:** ১২ মাসের বিস্তারিত হিসাবের টেবিল, বার্ষিক সঞ্চয়ের হার (%), খাতভিত্তিক বিশ্লেষণ এবং সরাসরি রিপোর্ট প্রিন্ট করার প্রিন্টার-ফ্রেন্ডলি লেআউট।
* **ব্যাকআপ:** গুগল ড্রাইভ ও অফলাইন লোকাল JSON/CSV ব্যাকআপ এবং রিস্টোর সুবিধা।
* **সেটিংস:** পরিবারের নাম, মাসিক বাজেট সীমা, ডিফল্ট পেমেন্ট মাধ্যম এবং ডেমো ডেটা লোডার।

### ৩. আর্থিক ডেটা সুরক্ষা ও ক্লাউড ব্যাকআপ
* **লোকাল স্টোরেজ পারসিস্টেন্স:** ব্রাউজার রিফ্রেশ করলেও কোনো ডেটা হারাবে না (`familyExpenseTracker.v1`)।
* **JSON ব্যাকআপ ও রিস্টোর:** যেকোনো সময় পুরো হিসাবের ফাইল ডাউনলোড বা আগের ব্যাকআপ রিস্টোর করা যায়।
* **CSV এক্সপোর্ট ও ইমপোর্ট:** এক্সেল বা স্প্রেডশিটে ব্যবহারের জন্য CSV ফাইল ডাউনলোড ও আপলোড সুবিধা।
* **Google Drive ক্লাউড ব্যাকআপ:** নির্ধারিত গুগল অ্যাকাউন্ট `rafiqulislam.globalwork@gmail.com`-এর সাথে অফিসিয়াল OAuth ইন্টিগ্রেশন।

## 🚀 দ্রুত শুরু ও লোকাল ব্যবহার (Quick Start)

### পদ্ধতি ১: অফলাইন ব্রাউজার মোড
কোনো সার্ভার ছাড়াই শুধুমাত্র `public/index.html` ফাইলটি যেকোনো ব্রাউজারে খুললে লোকাল স্টোরেজে সম্পূর্ণ আয়-ব্যয় ট্র্যাকিং, রিপোর্ট এবং JSON/CSV ডাউনলোড ফিচার ব্যবহার করা যাবে।

### পদ্ধতি ২: সম্পূর্ণ সার্ভার ও Google Drive মোড (Node.js)

১. প্রজেক্টের রুট ফোল্ডারে টার্মিনাল খুলে ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

২. সার্ভার চালু করুন:
```bash
npm start
```

৩. ব্রাউজারে ভিজিট করুন:
```
http://localhost:3000
```

## ☁️ Google Drive ব্যাকআপ সেটআপ নির্দেশিকা

অ্যাপ্লিকেশনটি গুগল ড্রাইভের `Family Expense Backup` ফোল্ডারে স্বয়ংক্রিয়ভাবে টাইমস্ট্যাম্পসহ JSON ব্যাকআপ সংরক্ষণ করতে পারে।

### সেটআপের ধাপসমূহ:
1. **Google Cloud Console**-এ যান: [https://console.cloud.google.com/](https://console.cloud.google.com/)
2. নতুন প্রজেক্ট তৈরি করে **APIs & Services** থেকে **Google Drive API** এনাবল করুন।
3. **OAuth consent screen** তৈরি করুন এবং আপনার গুগল অ্যাকাউন্ট `rafiqulislam.globalwork@gmail.com` টেস্ট ইউজার হিসেবে যোগ করুন।
4. **Create Credentials → OAuth client ID** (Application type: **Web application**) তৈরি করুন।
5. **Authorized redirect URIs**-এ এই URL যোগ করুন:
   ```
   http://localhost:3000/auth/google/callback
   ```
6. প্রজেক্টের `.env.example` ফাইলটি কপি করে `.env` তৈরি করুন এবং Client ID ও Client Secret বসান:
   ```env
   PORT=3000
   GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
   GOOGLE_CLIENT_SECRET=your-client-secret
   GOOGLE_REDIRECT_URI=http://localhost:3000/auth/google/callback
   GOOGLE_ACCOUNT_EMAIL=rafiqulislam.globalwork@gmail.com
   ```
7. সার্ভার রিস্টার্ট করে অ্যাপ্লিকেশনের **ব্যাকআপ → Google Drive সংযোগ করুন** বাটনে চাপ দিয়ে পারমিশন দিন।
8. অনুমতি সফল হলে **এখনই ক্লাউডে ব্যাকআপ নিন** বাটনে চাপ দিলেই ফাইল ড্রাইভে চলে যাবে এবং অ্যাপে সরাসরি ড্রাইভ ফাইলের লিঙ্ক ও রিস্টোর বাটন দেখা যাবে।
