Drive সংযোগ অবস্থা পরীক্ষা করা হচ্ছে…

সার্ভার থেকে গুগল ড্রাইভ কনফিগারেশন যাচাই করা হচ্ছে।

নির্ধারিত অ্যাকাউন্ট: rafiqulislam.globalwork@gmail.com
নিরাপত্তা তথ্য: অ্যাপটি আপনার গুগল পাসওয়ার্ড কখনো চাইবে না। শুধুমাত্র অফিসিয়াল গুগল ওঅথ (OAuth) ব্যবহার করে অনুমতিপ্রাপ্ত ফোল্ডারে ব্যাকআপ ফাইল রাখে।

সতর্কতা: ব্রাউজার ক্যাশ বা হিস্ট্রি ক্লিয়ার করলে লোকাল হিসাব মুছে যেতে পারে। তাই মাসে অন্তত একবার JSON ফাইল ডাউনলোড অথবা Google Drive ব্যাকআপ রাখুন।

Google Drive সেটআপ করার সহজ নির্দেশিকা

  1. Google Cloud Console (console.cloud.google.com)-এ লগইন করে একটি নতুন প্রজেক্ট তৈরি করুন।
  2. APIs & Services থেকে Google Drive API চালু (Enable) করুন।
  3. OAuth consent screen সেটআপ করুন এবং ইউজার টাইপ External দিন। নিজের গুগল অ্যাকাউন্ট rafiqulislam.globalwork@gmail.com টেস্ট ইউজার হিসেবে যোগ করুন।
  4. Credentials সেকশনে গিয়ে Create Credentials → OAuth client ID নির্বাচন করুন (Application type: Web application)।
  5. Authorized redirect URIs-তে যোগ করুন: http://localhost:3000/auth/google/callback (লাইভ সাইটের ক্ষেত্রে ডোমেইন URL)।
  6. প্রজেক্টের .env.example ফাইলটি কপি করে .env নামে সেভ করুন এবং প্রাপ্ত GOOGLE_CLIENT_ID ও GOOGLE_CLIENT_SECRET বসান।
  7. টার্মিনালে npm start কমান্ড দিয়ে সার্ভার চালু করে উপরে Google Drive সংযোগ করুন বাটনে ক্লিক করুন।
